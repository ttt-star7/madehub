# 造物集 MadeHub — AI 造物市集

发现、分享、出售你用 AI 创造的一切：Skill、软件、插件、素材、模型。

纯前端静态站点（零依赖、零构建）：`index.html` + `styles.css` + `app.js`。

## 功能

- 探索：方形卡片网格、标签/价格/类型筛选、排序、热门标签快选搜索
- 排行榜：标签筛选 × 日榜/周榜/月榜/年榜/神榜（历史 Top 50）
- 社区：动态发布、点赞、评论、话题
- 创作者主页：玻璃身份卡、成就徽章、统计、创作活跃度热力条、作品/动态/评价
- 创作者中心：收益看板（手续费 5% · 担保交易 · 确认收货打款）、作品管理（审核流）、提现、设置
- 上传：网盘链接自动识别（百度/阿里/夸克/蓝奏/123/天翼/微云/OneDrive）、封面自定义裁剪、内容图片、违规审核
- 账号：邮箱/手机号注册登录、微信/QQ 扫码授权（演示）、深色模式、通知中心

> 当前为前端演示：数据保存在内存中，刷新后重置；支付、登录、审核为模拟流程。

## 本地运行

直接双击 `index.html`，或：

```bash
python -m http.server 8931
# 打开 http://127.0.0.1:8931
```
